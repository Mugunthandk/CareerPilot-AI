# 🌟 Why Choose CareerPilot AI?

CareerPilot AI is an AI-powered career development platform designed to help students prepare for placements through personalized learning, resume analysis, coding practice, mock interviews, and career guidance.

---

# 🚀 Key Features

- 🤖 AI Resume Analysis
- 📄 ATS Resume Score
- 🧠 AI Career Recommendations
- 💻 Coding Practice
- 🎤 AI Mock Interviews
- 📊 Analytics Dashboard
- 📅 Daily Study Planner
- 🎯 Skill Gap Analysis
- 📈 Placement Readiness Score
- 🔒 Secure Authentication
- 📱 Responsive Design
- ☁️ Cloud Ready
