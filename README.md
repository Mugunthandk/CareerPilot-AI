# 📖 Overview

CareerPilot AI is a modern AI-powered placement preparation platform designed to help students become industry-ready through intelligent career guidance, resume optimization, interview preparation, coding practice, and performance analytics.

The platform provides a unified ecosystem where students can monitor their placement journey, improve their skills, and receive personalized AI recommendations.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Mugunthandk/CareerPilot-AI.git
```

## Navigate

```bash
cd CareerPilot-AI
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Visit

```
http://localhost:5173
```
