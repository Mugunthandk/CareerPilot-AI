# 📖 Overview

CareerPilot AI is a modern AI-powered placement preparation platform built to help students become job-ready through intelligent career guidance and a unified learning experience.

The platform combines resume analysis, interview preparation, coding practice, career tracking, and AI-powered insights in a clean and responsive dashboard.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Mugunthandk/CareerPilot-AI.git
```

---

## Navigate

```bash
cd CareerPilot-AI
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
